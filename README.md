# 1億2千万分の1 — 日本に生まれる人生シミュレーション

https://1injp.satoru.net/

日本のどこかに、誰かとして生まれて、一生を生きるブラウザゲーム。
生まれる場所・名字・名前・親・学校・仕事・結婚・病気・死因まで、できるだけ公的統計などの実データにもとづいて抽選します。
[1in8b.life](https://1in8b.life/ja/) の日本版として作りました（文章やコードは独自です）。

## 特徴

- **実データで抽選** — 人口動態統計・国勢調査・簡易生命表などをもとに、都道府県や市区町村、実在の学校・病院・企業まで出てきます。
- **寿命の補正** — 年齢ごとの死亡リスクを調整して、たくさん生きた結果の平均寿命が「令和7年簡易生命表」（男81.35歳・女87.33歳）に近くなるようにしています。
- **選択とその結果** — 進路・就職・結婚・住まい・投票などを自分で選べます。LINE・電話・手紙、マークシート、給与明細、健診結果、婚姻届などの画面で選び、その選択が後の人生に影響します。
- **時代モード** — 現代 / 平成 / 昭和後期 / 昭和 / 戦時中 / ランダム。生まれ年に合わせて、名前の流行、連絡手段（手紙→黒電話→ポケベル→ガラケー→スマホ）、当時の会社、物価、出来事が変わります。
- **ドット絵の場面・BGM** — 出来事ごとのピクセルアートと、Web Audio で合成したドビュッシー「月の光」（Mutopia Project のパブリックドメイン MIDI から生成）。
- **人生の記録の共有** — 終えた人生は共有ページ `/l/<id>` とOG画像になり、みんなの人生の一覧 `/lives` とランキング `/rank` に載ります。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面とスタイル |
| `app.js` | UI（画面遷移、選択肢、電話・書類の画面、フィード、保存と再開） |
| `engine.js` | シミュレーション本体（Node.js でもブラウザでも動く） |
| `data.js` | 基本データ（手書き） |
| `data_real.js` | 実データ（**自動生成**：`tools/build_data.py`。直接編集しない） |
| `data_showa.js` / `data_heisei.js` | 昭和・平成の流行や出来事 |
| `japanmap.js` | 日本地図（国土地理院データを加工したSVG）と市区町村の座標 |
| `illust.js` / `pxscenes.js` / `stork3d.js` | SVGイラスト、ドット絵の場面、three.js のコウノトリ |
| `audio.js` / `clair.js` | BGM・効果音の合成と「月の光」の譜面データ |
| `server/lifelog.py` | 人生の記録の保存API・共有ページ・OG画像・ランキング（Python 標準ライブラリ + Pillow、SQLite） |
| `tools/build_data.py`, `tools/src/*.json` | 集めた統計データと、`data_real.js` を作るスクリプト |

## 動かし方

ゲーム本体は静的ファイルだけで動きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

実データを更新したら、`data_real.js` を作り直します。

```sh
python3 tools/build_data.py
```

記録の共有サーバー（任意）:

```sh
pip install pillow
# server/fonts/ に NotoSansJP.ttf と ShipporiMincho-ExtraBold.ttf を置く（リポジトリには含めていません）
python3 server/lifelog.py      # 127.0.0.1:8095（環境変数 PORT で変更可）
```

本番では nginx が `/api/ /l/ /og/ /ph/ /lives /rank` を `127.0.0.1:8095` に転送し、`/server/` と `/tools/` へのアクセスは 404 にしています。
`index.html` で読み込む JS/CSS には `?v=<タイムスタンプ>` を付けてキャッシュを避けているので、ファイルを変更したら値を上げてください。

## データの出典（主なもの）

- 厚生労働省「人口動態統計」「簡易生命表」「国民生活基礎調査」「賃金構造基本統計調査」
- 総務省「国勢調査」「住宅・土地統計調査」「労働力調査」
- 文部科学省「学校基本調査」「学校コード一覧」、児童生徒の問題行動・不登校等調査
- 国立社会保障・人口問題研究所「日本の将来推計人口（令和5年推計）」
- 国立がん研究センター がん統計、地震調査研究推進本部
- 名字由来net、明治安田生命「生まれ年別の名前調査」、各種就職人気ランキング・偏差値ランキング
- 地図：地球地図日本（国土地理院）を加工、住所位置：Geolonia 住所データ（CC BY 4.0）

項目ごとの詳しい出典は `tools/src/sources_all.json` と、ゲーム内の「データについて」にあります。
大学の偏差値や企業の年収などは概算を含みます。昭和・平成の流行データには未検証のものもあります。
